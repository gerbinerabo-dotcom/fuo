# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View in AI Studio: https://ai.studio/apps/95771a8d-f6b9-4849-8f7f-b6f6190c39be

## Run Locally

**Prerequisites:** Node.js 22.12+ or 20.19+

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and add your Gemini API key if needed.
3. Run the app: `npm run dev`
